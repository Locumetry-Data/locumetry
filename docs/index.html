Start

Base URL https://locumetry.com/api/v1. Every request is a GET, every response is JSON, and every request except /health carries your key in the X-API-Key header.

curl -s https://locumetry.com/api/v1/districts/TR_06_1747 \
  -H "X-API-Key: $LOCUMETRY_API_KEY"
import requests

api = requests.Session()
api.headers["X-API-Key"] = "your key"
BASE = "https://locumetry.com/api/v1"

sincan = api.get(f"{BASE}/districts/TR_06_1747").json()
print(sincan["geo"]["name"], sincan["scores"]["affluence_score"]["percentile"])
const res = await fetch("https://locumetry.com/api/v1/districts/TR_06_1747", {
  headers: { "X-API-Key": process.env.LOCUMETRY_API_KEY },
});
const sincan = await res.json();
console.log(sincan.geo.name, sincan.labels.map(l => l.label));

Keys come with a plan from the pricing page; for an evaluation key write to hello@locumetry.com. Runnable versions of everything on this page are in the examples folder.

Authentication

The key goes in the header only. A key in the URL would end up in access logs, so query-string keys are not accepted. A missing or unknown key answers 401; more requests per minute than your plan allows answers 429 with a Retry-After header saying how many seconds to wait. Each key is metered per day and route, and you can read your own meter at /usage.

Identifiers

Places are addressed by stable identifiers, never by name. Names change spelling and case between sources; identifiers do not.

TR_06
a province, by plate code (Ankara)
TR_06_1747
a district, by TÜİK district code (Sincan)
TR_06_1747_1838
a neighbourhood inside that district
TR5
a NUTS1 region, used by the region filter (TR1 İstanbul, TR2 West Marmara, TR3 Aegean, TR4 East Marmara, TR5 West Anatolia, TR6 Mediterranean, TR7 Central Anatolia, TR8 West Black Sea, TR9 East Black Sea, TRA Northeast Anatolia, TRB Central East Anatolia, TRC Southeast Anatolia)

To find an identifier, list a province's districts with /districts?province=TR_06 or search by name with /districts?q=sincan. Every geography object also carries region_code, nuts3_code, a centroid and its area.

Reading the numbers

Scores are percentiles

percentile is the district's standing among all districts (or among provinces for the two province-level scores): 90 means higher than 90 percent of them. score_value is the underlying 0–100 value, rank_national and rank_region the positions.

Features carry a period

Every feature value comes with the year it describes; observations carry the exact period_date (first day of the year, quarter or month) and the source_id.

Estimates are flagged

is_estimated: true marks a value that was allocated from a provincial or national figure rather than measured for that district. Treat it as context, not as a fact about the district.

GET/screen

The site-selection query. Districts that carry every label, none of without_label, and stand at or above / below the given national percentiles, inside an optional province, region or population band, sorted by a score.

min_score
list of score_id:percentile, e.g. affluence_score:75; district-level scores only
max_score
list of score_id:percentile, e.g. commercial_saturation_score:50
label, without_label
lists of label ids the district must carry / must not carry
province, region
TR_35; TR3
min_population, max_population
latest population bounds
sort
a district-level score, default commercial_opportunity_score
limit
1 to 1000, default 100

Recipes

A site-selection screen

"Affluent, gaining momentum, not yet commercially saturated, with at least 100,000 residents." Thresholds are national percentiles; start loose and tighten.

hits = api.get(f"{BASE}/screen", params={
    "min_score": ["affluence_score:75", "economic_momentum_score:60"],
    "max_score": ["commercial_saturation_score:50"],
    "min_population": 100000,
    "sort": "commercial_opportunity_score",
    "limit": 25,
}).json()
for d in hits:
    s = d["scores"]
    print(f'{d["name"]:<14} {d["province"]:<10} opp {s["commercial_opportunity_score"]["percentile"]:5.1f}'
          f'  afflu {s["affluence_score"]["percentile"]:5.1f}  satur {s["commercial_saturation_score"]["percentile"]:5.1f}')

Labels make the same question shorter: label=high_growth_underserved&min_population=100000 returns the districts that are growing fast with below-median saturation, 19 of them at the time of writing, Sincan first.

Compare a shortlist

ids = ["TR_06_1747", "TR_35_1521", "TR_41_2061"]
rows = [api.get(f"{BASE}/districts/{g}").json() for g in ids]
for r in rows:
    pct = {k: round(v["percentile"]) for k, v in r["scores"].items() if v["level"] == "district"}
    pop = r["features"]["population"]
    print(r["geo"]["name"], pop["value"], pop["year"], pct["affluence_score"], pct["economic_momentum_score"],
          [l["label"] for l in r["labels"]])

Track a district over time

hist = api.get(f"{BASE}/districts/TR_06_1747/history",
               params={"feature": ["population", "workplaces_per_1000", "commercial_poi_density"]}).json()
for feature, series in hist.items():
    print(feature, [(p["year"], round(p["value"], 3)) for p in series[-5:]])

scores = api.get(f"{BASE}/scores/history", params={"geo_id": "TR_06_1747", "score": "affluence_score"}).json()
print([(p["year"], round(p["percentile"])) for p in scores["affluence_score"]])

Find lookalikes

You have one district that works. Ask for the ten most similar ones outside its own province, and read the differences before you believe the match.

twins = api.get(f"{BASE}/districts/TR_06_1747/similar", params={"limit": 10, "exclude_province": "true"}).json()
for t in twins:
    print(t["rank"], t["name"], t["province"], round(t["distance"], 2),
          "; ".join(f'{d["feature"]} {d["direction"]}' for d in t["differences"]))

Export to CSV

import csv
rows = api.get(f"{BASE}/rankings", params={"score": "economic_vitality_score", "limit": 1000}).json()
with open("economic_vitality.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["geo_id", "district", "province", "score", "percentile", "rank_national", "rank_region"])
    for r in rows:
        w.writerow([r["geo_id"], r["name"], r["province"], round(r["score_value"], 1), round(r["percentile"], 1),
                    r["rank_national"], r["rank_region"]])

Errors and limits

Data is rebuilt nightly; responses may be cached for a short time at the edge. Identifiers and field names are stable within v1; new fields may be added, existing ones are not renamed or removed without a new version.

Locumetry is information, not advice. The API is built to make a shortlist defensible and traceable, not to replace a visit.
